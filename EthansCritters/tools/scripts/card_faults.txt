# A card that stalls (M8a, src/engine/Card.h): every card user (the world,
# the frame cache, the willows' passes, the toad, the clips, the title)
# loses only its frame when a stream fails: the card is recovered
# (sd::recover()), the frame is not sent (the panel keeps the last one),
# and the next frame tries again; two lost in a row and the game waits
# with the screen; 40 in a row (or a card recover() cannot bring back) and
# it is the card screen. With the simulator's card as it is, nothing fails
# (Z: lost=0) and this is a walk past each card user. Run it with faults:
#   CHSD_SIM_CMD_US=832 CHSD_SIM_BLK_US=222 CHSD_SIM_FAIL_EVERY=7 CHSD_SIM_JITTER_US=2000
#     ec run tools/scripts/card_faults.txt out/card_faults
# (every 7th stream fails part way, costing the 32 ms timeout: the snaps
# are the same moments, a few frames later, never the card screen), or
#   CHSD_SIM_COLD_US=300000 (each 1 MB of the card 0.3 s late on its first
# read: the boot's warm-up, STIRRING THE SWAMP, takes them all; WARM ms=
# says how long). tools/tests/sim_card_faults.py runs both and checks.
wait 30
